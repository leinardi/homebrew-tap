# homebrew-tap

[Homebrew](https://brew.sh) tap for leinardi's projects.

## Install

```bash
brew install --cask leinardi/tap/monmux
```

Or tap once and install by name:

```bash
brew tap leinardi/tap
brew install --cask monmux
```

## What is here

| Cask | Project | Written by |
| --- | --- | --- |
| [`monmux`](Casks/monmux.rb) | [leinardi/monmux](https://github.com/leinardi/monmux) | monmux's release workflow (goreleaser) |

The casks are generated by the release pipelines of the projects they package and pushed here on every release. Report a
problem with a cask, and send a change to one, to the project it installs: a hand edit here is overwritten by the next
release.
